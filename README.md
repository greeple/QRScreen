# QR Screen

Небольшая portable-утилита для Windows: выделить участок экрана с QR-кодом, распознать его и скопировать содержимое в буфер обмена.

## Как пользоваться

1. Запустите `QRScreen.exe`. Программа свернётся в область уведомлений рядом с часами.
2. Нажмите назначенное сочетание клавиш (по умолчанию **Print Screen**).
3. Мышью выделите прямоугольник с QR-кодом. После отпускания кнопки мыши курсор переключается с крестика на обычную стрелку.
4. Нажмите **«Распознать QR»** или клавишу **Enter**.
5. Распознанный текст окажется в буфере обмена — его можно вставить через `Ctrl+V`.

Нажатие **Esc** отменяет выделение. Повторный запуск EXE не создаёт второй экземпляр: приложение работает в фоне одним процессом. Через контекстное меню значка в трее можно запустить распознавание вручную, изменить сочетание клавиш или закрыть программу.

## Настройка горячей клавиши

Откройте контекстное меню значка QR Screen в трее → **«Настройки сочетания клавиш...»**. Щёлкните по полю и нажмите нужную комбинацию. Print Screen можно назначить отдельно или вместе с Ctrl, Alt, Shift и Win; для остальных клавиш нужен модификатор. Поле настроек перехватывает Print Screen напрямую, потому что Windows не всегда передаёт эту клавишу обычному полю ввода.

При запуске и при сохранении настройки программа пытается зарегистрировать сочетание через Windows `RegisterHotKey`. Если оно уже зарегистрировано другой программой, QR Screen автоматически пробует альтернативы, включая сочетания с Print Screen и Ctrl+Alt+F11. О переназначении программа сообщает обычным диалоговым окном с кнопкой OK, без всплывающих уведомлений Windows. Если выбранная вручную комбинация занята, текущая комбинация остаётся активной.

**Ограничение Windows:** надёжно проверить занятость можно для сочетаний, зарегистрированных другими приложениями через `RegisterHotKey`. Windows не предоставляет способа узнать все программы, которые перехватывают клавиши собственными низкоуровневыми хуками или Raw Input. Такие конфликты невозможно гарантированно обнаружить заранее.

Настройки сохраняются в `QRScreen.ini` рядом с EXE. Это позволяет переносить программу вместе с настройкой сочетания клавиш.

Если в области найдено несколько QR-кодов, содержимое каждого копируется в буфер обмена, разделённое пустой строкой. Повторяющиеся значения не дублируются.

## Особенности

- Работает локально, без интернета и отправки изображений на сервер.
- Поддерживает виртуальный рабочий стол с несколькими мониторами.
- Распознаёт QR-коды, в том числе повёрнутые и инвертированные.
- Один EXE: ZXing-C++ статически линкуется, MSVC runtime также статический.
- Не сохраняет скриншоты на диск.
- Копирует распознанное содержимое в буфер обмена сразу в двух форматах: исходный Unicode-текст и CF_HTML. Word и другие редакторы с поддержкой HTML получают форматированную вставку, если QR содержит HTML; обычные текстовые редакторы получают исходный текст. Для обычного текста HTML-представление создаётся автоматически с сохранением переводов строк. Из HTML удаляются активные элементы, обработчики событий и небезопасные ссылки; основные теги форматирования, безопасные CSS-блоки и inline CSS сохраняются.

Требуется Windows 10 или Windows 11.

## Сборка через GitHub Actions

1. Создайте пустой GitHub-репозиторий.
2. Загрузите в него все файлы и папки из этого архива, сохранив структуру `.github/workflows/build.yml`.
3. Откройте вкладку **Actions** и запустите workflow **Build QR Screen** (или сделайте push в `main`/`master`).
4. В завершившемся запуске скачайте artifact **QRScreen-Windows-x64**.

Если создать тег вида `v1.0.0` и отправить его в репозиторий, workflow дополнительно создаст GitHub Release с ZIP-архивом программы.

## Библиотека распознавания

Используется [ZXing-C++](https://github.com/zxing-cpp/zxing-cpp), версия 3.1.1, с лицензией Apache-2.0. При конфигурации сборки CMake скачивает исходники библиотеки и включает только QR-декодер. Текст лицензии сторонней библиотеки приложен в `THIRD_PARTY_LICENSES/ZXing-Apache-2.0.txt`.
